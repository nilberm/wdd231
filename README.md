# wdd231

WDD 231 – Frontend Web Development I coursework for Nilber Mota.

Published at: https://nilberm.github.io/wdd231/

## Structure

- `index.html` – course home page
- `styles/` – `normalize.css`, `small.css` (mobile-first base), `larger.css` (media queries)
- `scripts/` – `navigation.js` (responsive menu), `date.js` (footer year + last modified), `course.js` (certificate course list + filtering)
- `images/` – logo, favicon, and photo assets

## Notes

- `images/profile.svg` is a placeholder. Replace it with an optimized photo (≤ 125 kB) and update the `<img>` / `og:image` references in `index.html`.
